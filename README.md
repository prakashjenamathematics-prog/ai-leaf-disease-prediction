## 📖 Overview

The AI Leaf Disease Prediction System is a Deep Learning-based web application that detects plant leaf diseases from uploaded images. It helps farmers and researchers identify diseases quickly and accurately using a trained CNN model.

---

## 🚀 Features

- Plant Leaf Disease Detection
- Image Upload
- CNN-Based Prediction
- Disease Information
- User-Friendly Flask Interface
- Fast and Accurate Results

## ⚙ Installation

Clone Repository

```bash
git clone https://github.com/prakashjenamathematics-prog/ai-leaf-disease-prediction.git
```

Move into folder

```bash
cd ai-leaf-disease-prediction
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Project

```bash
python app.py
```

Open Browser

```
http://127.0.0.1:5000
```
